# jankenpo-csharp

Jogo de pedra, papel e tesoura escrito em C#. Desenvolvi no Linux, usando o runtime Mono — a instalação está no site oficial do projeto.

# Compilar

Com o compilador do Mono:

`
csc jankenpo.cs
`


---

# Executar

Depois de compilar:

`
mono jankenpo.exe
`

# Vídeo

Há uma gravação com o jogo rodando no terminal.
